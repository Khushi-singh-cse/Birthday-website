BIRTHDAY WEBSITE — QUICK SETUP

1. Keep index.html, style.css and script.js in the same folder.
2. Add your legally obtained MP3 copy of the exact song version you want and name it: song.mp3
3. Later, record your voice note and save it as: voice-note.mp3
4. Open index.html in a browser to test. For sharing online, upload the whole folder to a static host such as GitHub Pages or Netlify.

To personalise:
- Edit the birthday text in index.html.
- Replace emoji/photo placeholders in the memory section with your images.
- Music starts only after a click because browsers restrict autoplay with sound.
- This is a close recreation of the reference's scrapbook/polka-dot birthday flow, not a pixel-perfect copy; the video does not expose its original source code or image assets.
